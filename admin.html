🔐 관리자 인증

GitHub 토큰 만드는 방법
1. bough38-web 계정으로 GitHub 로그인 → Fine-grained token 만들기
2. Token name: 정책문서 업로드, Expiration: 원하는 기간(예: 90일)
3. Repository access: Only select repositories → Pllicy-Standards-2026-04
4. Permissions → Repository permissions → Contents: Read and write
5. Generate token → 나온 github_pat_… 값을 위 칸에 붙여넣기
